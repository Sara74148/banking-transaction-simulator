# banking-transaction-simulator
The Banking Transaction Simulator is a desktop application developed using Java to simulate basic banking operations. It allows users to create bank accounts, perform deposits, withdrawals, and fund transfers, while maintaining transaction history and pending transactions. The project was developed to demonstrate the practical implementation of Data Structures and Algorithms in a real-world banking system.

## Features
- Create new bank accounts
- Deposit money
- Withdraw money
- Transfer funds between accounts
- View account details
- View transaction history
- Process pending transactions
- Undo processed transactions
- Priority-based transaction processing for VIP accounts
- Input validation for accounts and transactions

## Technologies Used
- Java
- Java Swing
- File Handling
- BufferedReader & BufferedWriter
- IntelliJ IDEA

## DSA Concepts Used
- Custom Doubly Linked List
- Custom Priority Queue
- HashMap
- Comparator
- Singleton Design Pattern
